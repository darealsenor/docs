# Installation

Upgrading from `senor_topplayers`? Follow the [V2 Migration guide](/docs/scripts/topplayers/v2-migration/) before replacing the resource.

The installation steps below describe v1. Use the v2 guide for `senor_leaderboard`.

<Aside type="note">
This resource must run after <a href={links.thirdParty.ox_lib}>ox_lib</a> and requires <a href={links.thirdParty.oxmysql}>oxmysql</a>.
</Aside>

## Prerequisites

- <a href={links.thirdParty.ox_lib}>ox_lib</a>
- <a href={links.thirdParty.oxmysql}>oxmysql</a>

## File System should look like this

```plaintext
resources/
  └── senor-topplayers/
      ├── client/
      ├── server/
      ├── bridge/
      ├── config/
      ├── data/
      ├── locales/
      ├── stream/
      ├── web/
      └── fxmanifest.lua
```

<Aside type="note">
Keep the resource name as `senor-topplayers` or it will not work.
</Aside>

## Database Setup

The SQL tables will auto-create, so you don't need to run any SQL files manually.

## Start the Resource

```cfg
ensure senor-topplayers
```

## Verify Installation

1. Start server
2. Join in-game
3. Use `/topplayers` to open the leaderboard
4. Use `/topplayersadmin` to open the admin panel (admin only)
